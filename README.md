## 📌 Proje Hakkında
Bu proje, **ASP.NET Core** ve **Razor Pages** kullanılarak geliştirilmiş bir **Görev Yönetim Sistemi (Task Management System)** web uygulamasıdır.  
Amaç, kullanıcıların görevlerini takip edebilmesi, rollerine göre yetkilendirilmesi ve veritabanı üzerinden güvenli bir şekilde yönetim yapılmasını sağlamaktır.

## 🚀 Özellikler
- Görev ekleme, düzenleme, silme ve filtreleme
- Kullanıcı rolleri (Admin / Kullanıcı)
- Entity Framework Core ile migration ve CRUD işlemleri
- Bootstrap ve özel CSS ile modern arayüz
- Git ve GitHub ile versiyon kontrolü
- Refactoring ve modüler yapı

## 🛠️ Kullanılan Teknolojiler
- **Backend:** ASP.NET Core  
- **Frontend:** Razor Pages, Bootstrap, CSS  
- **ORM:** Entity Framework Core  
- **Database:** MSSQL / LocalDB  
- **IDE:** Visual Studio 2022  
- **Version Control:** Git & GitHub
-
